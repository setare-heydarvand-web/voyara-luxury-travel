# VOYARA — Luxury Travel Experience

A modern luxury travel website designed to inspire exploration and create an immersive digital journey.

VOYARA combines elegant visual storytelling, smooth scrolling, and interactive animations to present destinations and curated travel experiences through a refined interface.

## Overview

VOYARA is a front-end web project focused on creating a premium travel experience with a clean layout, immersive imagery, and smooth interactions.

The website is designed to bring destinations to life through carefully arranged sections, visual transitions, and scroll-based animations.

## Features

- Elegant and responsive user interface
- Immersive hero section
- Destination showcases
- Curated travel experiences
- Interactive journey section
- Smooth scrolling experience
- Scroll-triggered animations
- Responsive navigation and mobile menu
- Optimized layouts for different screen sizes

## Technologies

- HTML5
- CSS3
- Tailwind CSS v4
- JavaScript
- GSAP
- GSAP ScrollTrigger
- Lenis

## Animation & Interaction

VOYARA uses GSAP and ScrollTrigger for scroll-based animations and interactive visual effects.

Lenis provides smooth scrolling throughout the website, creating a more fluid browsing experience.

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/setare-heydarvand-web/voyara.git
```

### 2. Navigate to the project directory

```bash
cd voyara
```

### 3. Install dependencies

```bash
npm install
```

### 4. Run Tailwind CSS

```bash
npx @tailwindcss/cli -i ./css/input.css -o ./css/output.css --watch
```

Open `index.html` using a local development server such as VS Code Live Server.

## Deployment

The project is intended to be deployed using GitHub Pages.
